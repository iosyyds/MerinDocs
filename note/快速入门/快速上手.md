# 快速上手

> 占位符文档 — 请替换为实际快速上手指南。

## 创建第一篇文档

在 `note/` 目录下新建一个 `.md` 文件，例如：

```markdown
# 我的第一篇文档

这是我的文档内容。
```

保存后刷新页面，左侧导航栏就能看到它了。

## 组织分类

在 `note/` 下创建子文件夹来分类：

```
note/
├── README.md          # 首页
├── 前端开发/
│   ├── HTML.md
│   ├── CSS.md
│   └── JavaScript.md
└── 后端开发/
    ├── Node.js.md
    └── Python.md
```

## 支持的 Markdown 语法

- 标题（H1 ~ H6）
- 加粗、斜体、删除线
- 有序/无序列表
- 代码块（带高亮）
- 引用块
- 表格
- 链接和图片
