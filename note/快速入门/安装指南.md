# 安装指南

> 占位符文档 — 请替换为实际安装说明。

## 环境要求

- Node.js >= 18
- npm 或 yarn

## 安装步骤

### 1. 克隆项目

```bash
git clone <仓库地址>
cd <项目目录>
```

### 2. 安装依赖

```bash
npm run install:all
```

### 3. 准备文档

把你的 Markdown 笔记放进 `note/` 目录。

### 4. 启动开发服务器

```bash
npm run dev
```

打开浏览器访问 `http://localhost:3000` 即可。

## 生产部署

```bash
npm run build
npm start
```
