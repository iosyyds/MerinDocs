# 欢迎使用占位符文档站

这是一个基于 **MerinDocs** 同款模板搭建的占位符文档站。

## 这是什么？

这是一个轻量、开箱即用的 Markdown 文档站系统，支持：

- 📝 纯 Markdown 驱动，把 `.md` 文件放进 `note/` 就是一篇文档
- 🗂️ 分类导航侧边栏，按文件夹自动生成目录树
- 🔍 全文搜索
- 🎨 代码高亮 + 一键复制
- 📑 右侧目录大纲（TOC）
- 🌙 深色 / 浅色模式切换

## 快速开始

1. 把你的 Markdown 文件放进 `note/` 目录
2. 按分类创建子文件夹
3. 刷新页面即可看到新文档

> 这是一段占位符内容，请替换为你自己的文档。

## 示例代码

```javascript
function hello(name) {
  console.log(`Hello, ${name}!`);
}

hello("World");
```
