# 站点配置

> 占位符文档 — 请替换为实际配置说明。

编辑 `server/site.config.json` 来自定义站点：

```json
{
  "siteTitle": "我的文档站",
  "navbar": {
    "title": "我的文档",
    "buttons": [
      { "text": "返回首页", "url": "/", "target": "_self" }
    ]
  },
  "footer": {
    "copyrightText": "© 2024 我的公司",
    "poweredByText": "由 MerinDocs 驱动"
  }
}
```

修改后刷新浏览器即可生效，无需重启服务。

## 配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `siteTitle` | 浏览器标签页标题 | MerinDocs |
| `navbar.title` | 顶部导航栏标题 | MerinDocs |
| `navbar.buttons` | 导航栏右侧按钮列表 | - |
| `footer.copyrightText` | 页脚版权文字 | Tinsur |
| `footer.beian.icpText` | ICP 备案号 | 空 |
